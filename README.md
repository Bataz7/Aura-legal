Privacy Policy

Welcome to Aura.

Your privacy is important to us. This Privacy Policy explains what information Aura may collect, how it is used, and how it is protected.

Information We Collect

Aura may collect limited information required to operate correctly, including:

Discord User IDs
Discord Server IDs
Channel IDs
Role IDs
Message IDs (only when necessary for moderation or logging)
Configuration settings created by server administrators

Aura does not collect passwords, payment information, or personal messages unless explicitly required for a feature provided by the server.

How We Use Information

The collected information is used only to:

Provide bot functionality
Store server configuration
Improve reliability and performance
Prevent abuse and security threats
Generate moderation logs when enabled
Data Storage

Data is stored securely and only for as long as necessary to provide Aura's services.

Data Sharing

Aura does not sell, rent, or trade user data.

Information may only be shared when required by law or to protect the security and integrity of the service.

Security

Reasonable technical and organizational measures are implemented to help protect stored information from unauthorized access or misuse.

User Rights

Server owners may request removal of their server's stored configuration by contacting the Aura team.

Changes

This Privacy Policy may be updated at any time. Continued use of Aura after changes constitutes acceptance of the updated policy.

Contact

For questions regarding this Privacy Policy, please contact the Aura team.
